# Online Education System (OES)

## Project Overview

Online Education System is a web-based application developed to provide an online examination platform for students. The system allows users to register, attempt multiple-choice questions (MCQs), submit answers, and view their results instantly.

The main objective of this project is to make the examination process simple, fast, and accessible through an online platform.

---

## Features

- Student registration and login system
- User-friendly interface
- Online MCQ examination
- Multiple questions with options
- Automatic result calculation
- Score display after exam submission
- Question management system
- Database integration using MongoDB
- Responsive web design
